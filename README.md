# Coffee Service 

 

Навчальний SPA-застосунок для перегляду меню та оформлення попередніх замовлень у кав'ярні.

 

## Функціональні можливості 

 

- каталог товарів із категоріями, фотографіями та цінами; 

- фільтрація меню без перезавантаження сторінки; 

- кошик зі зміною кількості та підрахунком суми; 

- оформлення замовлення з ім'ям і часом самовивозу; 

- додавання, редагування та видалення товарів в адмін-панелі; 

- перегляд замовлень адміністратором; 

- захист адміністративних запитів тимчасовим токеном; 

- адаптивний інтерфейс і повідомлення про помилки. 

 

## Структура проєкту 

 

### Frontend 

 

- `main.jsx` — запуск React і підключення стилів; 

- `App.jsx` — маршрути та стан авторизації; 

- `api.js` — HTTP-запити через Fetch API; 

- `MenuPage.jsx` — каталог, категорії та стан кошика; 

- `CartModal.jsx` — склад кошика й форма замовлення; 

- `AdminLogin.jsx` — вхід адміністратора; 

- `AdminPage.jsx` — керування товарами та замовленнями; 

- `styles/` — загальні, клієнтські й адміністративні стилі. 

 

### Backend 

 

- `server.js` — Express-сервер, MongoDB і роздача frontend; 

- `models/Product.js` — модель товару; 

- `models/Order.js` — модель замовлення; 

- `routes/products.js` — маршрути товарів; 

- `routes/orders.js` — маршрути замовлень; 

- `routes/admin.js` — вхід, перевірка сесії та вихід; 

- `auth/adminAuth.js` — створення і перевірка токенів. 

 

## REST API 

 

| Метод | Маршрут | Призначення | 

| --- | --- | --- | 

| GET | `/api/products` | Отримати меню | 

| POST | `/api/orders` | Створити замовлення | 

| POST | `/api/products` | Додати товар | 

| PUT | `/api/products/:id` | Змінити товар | 

| DELETE | `/api/products/:id` | Видалити товар | 

| GET | `/api/orders` | Переглянути замовлення | 

 

Операції керування товарами та перегляд замовлень доступні лише після входу адміністратора. 

 

## Встановлення та запуск 

 

```bash 

npm --prefix backend install 

npm --prefix frontend install 

npm run start 

```

 

Сторінка: http://localhost:5000   

Адмін-панель: http://localhost:5000/admin   

Пароль: `coffee123` 

 

Якщо каталог порожній, товари можна додати через панель адміністратора.
